# ArchitecturalDrawingAnalyzer 操作説明書

建築図面（DXF／PDF）から部屋の境界・部屋名・面積を抽出し、画面で確認・修正して
CSV／Excel で出力するアプリの操作説明書です。

## 入手と起動

### Windows EXE（推奨）

1. GitHub のリポジトリで **Actions** → **Windows tests** を開きます。
2. 最新の成功した実行（緑のチェック）のページ下部 **Artifacts** から
   `ArchitecturalDrawingAnalyzer-Windows-Python312` をダウンロードします。
3. ZIP をフォルダーに展開し、展開先の `ArchitecturalDrawingAnalyzer.exe` を起動します。
   EXE だけを取り出さず、関連ファイルも含めて展開してください。

### Python から起動する場合

```bat
.\venv\Scripts\python.exe main.py
```

## 図面を開く

1. ツールバーの「📂 DXFを開く」から DXF ファイルを選びます。
2. 図面が表示され、左のパネルにレイヤー一覧、右のパネルに要素一覧が表示されます。
3. ズームは「🔍＋／－」、全体表示は「🔭 全体表示」（Fキー）です。
   マウスホイールでのズームとドラッグでの移動もできます。
4. レイヤーパネルでレイヤー名のチェックを外すと、そのレイヤーを非表示にできます。

### 図面の単位

- ツールバー右の「単位」で、図面の単位（mm／cm／m／in／ft）を確認・変更できます。
- 図面に記録された単位（`$INSUNITS`）と座標の桁数が矛盾している場合
  （例：座標が mm 単位の数値なのに単位がメートルになっている場合）は、
  ログに警告が出ます。その場合は単位を正しいものに変更してください。
- 単位を変更すると、部屋候補の検出から面積の計算まで自動でやり直します。

### 読み込めない要素がある場合

- 対応していない要素があっても読み込み全体は止まりません。
  未対応の要素はスキップされ、種類と件数がログに記録されます。
- 図面の要素数・レイヤー数はステータスバーとログで確認できます。

## PDF を開く

ベクトル PDF（CAD から出力された、線がベクトルデータで入っている PDF）
も開けます。スキャン PDF（画像だけの PDF）は対象外です。

### 開き方と換算率

1. ツールバーの「📂 図面を開く」から PDF ファイルを選びます。
2. 換算率を尋ねる画面が出ます。1pt あたりの mm 数を入力してください。
   - 換算率の考え方：図面の寸法値と PDF 上での長さの比です。
     例えば寸法 4000mm の線が PDF 上で 400pt なら、4000 ÷ 400 = 10mm/pt です。
   - 換算率が分からない場合は空欄のまま開けます。その場合は 1pt=1mm として
     読み込み、警告がログに出ます。開いた後、寸法に合わせて調整できます。
3. 図面が表示され、DXF と同じように部屋候補の検出や出力ができます。
   複数ページの PDF は 1 ページ目のみ読み込みます。

### 寸法照合の見方

PDF を読み込むと、寸法の照合を自動で行います。結果はログと、図面上の印で確認できます。

- 緑の印：寸法通り（実測長が寸法値と一致）
- 赤の印：不一致（実測長が寸法値と合っていない）
- 黄の印：要確認（寸法線の確信度が低く、確定できない）
- 灰の印：判定不能（測定対象の線が見つからない）

印をクリックすると、右のプロパティパネルに寸法値・実測長・差分・状態の
詳細が表示されます。印の表示／非表示は、ツールバーの
「📐 寸法照合を表示」で切り替えられます。

### 倍率調整の手順

線の長さが寸法通りでない（赤の印がある）場合は、倍率を調整して寸法に
合わせることができます。

1. ツールバーの「📐 寸法に合わせて倍率を調整」を押します。
2. 不一致の寸法のうち、確信度が最も高いものを使って換算率を計算し直し、
   図面全体を拡大・縮小し直します。
3. 調整の前後（換算率、使った寸法の寸法値と実測長）がログに記録されます。
   図面の再表示・寸法照合・部屋検出も自動でやり直します。
4. 調整対象の寸法がない場合（すべて一致している場合など）は、
   その旨を表示して何もしません。

倍率調整はこのボタンを押したときだけ行われます。自動で倍率は変わりません。

### PDF の制約

- スキャン PDF（画像のみ）は対象外です。読み込んでも線は検出されず、
  警告がログに出ます。OCR はこの版では対応していません。
- ベジェ曲線で描かれた線は対象外です。直線・矩形のみ読み込みます。
- 日本語フォントが埋め込まれていない PDF では、文字が文字化けして
  読み取れないことがあります。その場合は警告がログに出ます。
- 寸法の読み取りは、寸法テキストと寸法線・引出線の位置関係からの推測です。
  矢印や斜めの寸法線など、想定と違う描き方の寸法は「要確認」になるか、
  寸法として検出されないことがあります。

## 部屋候補の検出

1. ツールバーの「部屋候補を検出」を押します。
2. 閉じたポリラインと、線分（LINE）を組み合わせた閉領域の両方から
   部屋候補を検出します。隣接する部屋は別々の候補になります。
3. 検出した部屋は図面上に色分けして表示されます。
   - 黄色：要確認（検出直後はすべてこの状態です）
   - 緑色：確定
   - 灰色の破線：却下
4. 部屋をクリックすると、右の「部屋候補」パネルで名前と面積を確認できます。

### 検出できない場合

- 壁に大きな開口（ドアなど）があると、線分からは閉領域にならず部屋になりません。
  同じ輪郭が閉じたポリラインで描かれていれば部屋として検出されます。
- 円弧（ARC）や bulge を含む境界は、DXF版では未対応です。
  そのような部屋は検出されないか、一部のみ検出されることがあります。
- 1 m² 未満の小さな領域（柱など）は候補になりません。

## 部屋の確認・修正

右の「部屋候補」パネルで、選んだ部屋の確認・修正ができます。

- **部屋名**：名前の欄に入力して Enter を押すと変更できます。
  部屋の中に文字が1つだけある場合、自動で部屋名として関連付けられます。
  複数の文字がある場合や、寸法値のような文字の場合は自動では付けず、
  「要確認」のままになります。
- **確定／却下／要確認に戻す**：ボタンで状態を切り替えます。
  却下した部屋も一覧には残ります（「却下」と表示されます）。
- **削除**：誤検出した候補は「削除」ボタンで一覧と図面から取り除けます。
  削除した部屋は出力にも含まれません。
  ただし削除はアプリを起動している間だけ有効で、図面を読み込み直すと
  再検出されます。
- **面積基準**：「内法／壁芯」を切り替えられます。
  二重線の壁がある部屋では、壁芯で計算した面積も表示できます。
  壁芯面積が求まる部屋がない場合、「壁芯」は選べません。
  壁芯面積が求まらない部屋は、基準を「壁芯」にしても内法の面積のままです。

## 部屋一覧の出力

1. ツールバーの「💾 部屋一覧を出力」を押します。
2. CSV か Excel（.xlsx）を選んで保存します。
3. 出力には部屋番号・部屋名・面積（m²）・状態（確定／要確認／却下）・
   面積基準・候補種別・確信度が含まれます。
   ファイルの先頭には図面名・単位・出力日時が記録されます。
4. 削除した部屋は出力されません。

## 困ったときは

- 画面下部のログに、読み込み・検出・出力の結果と警告が記録されます。
  単位の警告や、未対応要素の件数もここで確認できます。
- 部屋が1件も検出されない場合は、図面の壁が閉じているか、
  円弧だけの境界になっていないかを確認してください。
- 面積が100万倍のようなおかしな値になった場合は、まず「単位」を
  確認してください。座標の数値と単位が合っていないことが原因です。
- PDF で寸法と実測長が合わない場合は、「📐 寸法に合わせて倍率を調整」を
  押してください。換算率が間違っていることが原因です。

## 対応範囲と制約

- 対応する図面形式：DXF（LINE／LWPOLYLINE／POLYLINE／ARC／CIRCLE／
  TEXT／MTEXT／INSERT）とベクトル PDF。スキャン PDF（画像のみ）は対象外です。
- 対応する部屋境界：直線で閉じた領域。円弧（ARC・bulge）を含む境界は
  未対応として扱います。
- 検出結果はあくまで候補です。自動で判断できない箇所は「要確認」として
  表示され、確定値としては扱いません。出力前に画面で確認してください。
